I'm a Computer Engineering student focused on solving real-world problems by connecting hardware, software, and data. I currently work in industrial automation and telemetry, developing robust data pipelines, analytical dashboards, and embedded electronics prototypes.

### 🚀 About Me

- 🔭 Currently working with **industrial telemetry dashboards** (Streamlit, GE Proficy Historian) and critical data automation via APIs.
- 🌱 Deepening my knowledge in **backend and web architectures** (.NET 9, C#, ASP.NET Core, FastAPI) and DevOps practices (Docker, AWS, GitHub Actions).
- ⚙️ Passionate about **IoT & Robotics**: building everything from self-balancing robots using ESP32 to custom access control systems (VoiceLock) and home automation.
- ⚡ Focus: Modular architectures, clean code, strict version control (Conventional Commits), and pragmatic solutions — from firmware to frontend.

### 📈 Featured Projects

*   **Telemetry Dashboards (Python/Streamlit):** Interfaces for monitoring and analyzing thousands of historian data tags (flow, pressure), using Pandas, Plotly, and custom HTML/CSS indicators.
*   **Industrial Data Pipelines:** Robust scripts with logging and scheduling (APScheduler) for extracting, sanitizing, and transmitting water volume data to regulatory agencies via OAuth2.
*   **VoiceLock & IoT:** Voice-activated access control and universal smart remote developed with ESP32, servo motors, IR LEDs, and Web Speech API integration.
*   **Containerized APIs (CI/CD):** Modern APIs (C#/.NET and FastAPI) with automated tests (Pytest) and deployment pipelines to GitHub Container Registry (GHCR) using GitHub Actions.
*   **Computer Vision Analytics:** Analytical tool in Python/OpenCV for color calibration and Region of Interest (ROI) mapping with real-time HUD gauges.
