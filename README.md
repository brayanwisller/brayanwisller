### 📈 Projetos em Destaque

*   **Dashboards de Telemetria (Python/Streamlit):** Interface para monitoramento e análise de milhares de tags de historiadores de dados (vazão, pressão), utilizando Pandas, Plotly e indicadores HTML/CSS customizados.
*   **Automação e Pipelines de Dados industriais:** Scripts robustos (com rotinas de logging e agendamento via APScheduler) para extração, higienização e transmissão OAuth2 de volumes hídricos para órgãos reguladores.
*   **VoiceLock & Projetos IoT:** Desenvolvimento de um controle de acesso ativado por voz utilizando ESP32, motores servo, LEDs infravermelhos e integração com a Web Speech API.
*   **APIs Conteinerizadas (CI/CD):** Construção de APIs modernas (C#/.NET e FastAPI) com testes automatizados (Pytest) e esteiras de deploy para o GitHub Container Registry via GitHub Actions.
*   **Computer Vision Analytics:** Ferramenta analítica em Python/OpenCV para calibração de cores e mapeamento de regiões de interesse (ROI) com medidores HUD em tempo real.
